# data/

Static data assets that ship with the code repo. The large derived files (dataset.jsonl, splits, prepared JSONLs) are hosted on Hugging Face at [`Niklas1102/mentalkg`](https://huggingface.co/datasets/Niklas1102/mentalkg).

## Files here

- **`variable_pool.json`**: controlled vocabulary of 133 concepts across 7 types (event, emotion, symptom, thought, stressor, activity, coping_action). Each concept has `concept_id`, `type`, `label`, `polarity`, and 3 English `example_phrases`. The pipeline uses this as the source of truth for what a node can be; the models learn from labels drawn from this pool.

## Files on the HF dataset

| file | rows | schema |
|---|---:|---|
| `dataset.jsonl` | 47,714 | one participant-day per line, full record (below) |
| `graphs.jsonl` | 48,104 | the graph pool the pipeline drew from |
| `variable_pool.json` | | copy of the file above |
| `splits.json` | | participant-independent 50/30/20 split, stratified by language, seed 42 |
| `node_prediction/train.jsonl` | 20,679 | `{example_id, text, language, labels: [concept_id, …]}` |
| `node_prediction/dev.jsonl` | 12,390 | same schema |
| `node_prediction/test.jsonl` | 8,246 | same schema |
| `node_prediction/labels.json` | | 130-label index (3 pool concepts have zero split support) |
| `edge_prediction/negative_match.json` | | per-split type-pair TV distance vs positives |
| `build_edge_split.py` | | rebuild edge splits from `dataset.jsonl + splits.json` |

Edge splits are rebuilt locally by a script: text repeats across every candidate pair from an entry, so shipping them flat would balloon the download to ~10 GB for the same information as ~600 MB of source text plus a rebuild script. Run:

```bash
python build_edge_split.py --data-dir .
```

## Vocabularies

- `node.type` ∈ `{event, emotion, symptom, thought, stressor, activity, coping_action}`
- `node.polarity` ∈ `{positive, negative, neutral, mixed}`
- `edge.type` ∈ `{causes, increases, decreases, follows, linked_to}`
- `node.time_anchor.text` ∈ `{today, now, tomorrow, later today, yesterday, last night, this morning, this afternoon, after that}`, each with a per-anchor `day_offset` and `temporal_status`.

## Corpus stats (accepted split)

- **41,315** samples over **3,410** participants, **14 days** each.
- Language: **20,982 EN / 20,333 DE**.
- Age range 16–75, mean 45.9.
- Writing style spread: rambling / matter_of_fact / emotional / terse_fragmented / reflective (roughly even).
- Per entry: median 5 nodes, 6 edges, 131 words.

Rebuild the stats table: `python scripts/stats.py`.

## Generation

Journal texts were generated by `openai/gpt-4o-mini` from ground-truth graphs. Each entry was verified by the same model against its source graph: node coverage, edge expression, temporal correctness, and hallucination counts. Thresholds gate the accept / review / reject decisions.

Both languages use identical guardrails: no connector phrases (`linked to`, `caused by`, `führte zu`, `verstärkte mein`), no clinical labels, no self-harm or violence content, per-writing-style word ranges. German entries were checked for idiomatic German phrasing (with connector-stem and inflection filters), so English calques get flagged and rewritten.
